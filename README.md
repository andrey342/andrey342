# Hi, I'm Andrey Kuzmin 👋

**Senior Full Stack Engineer** · .NET & Angular · Microservices with DDD, CQRS & Clean Architecture

Right now I'm building **MSG (MicroservicesGenerator)**, solo and in public: you design your .NET microservices visually (domain, APIs, events) and it generates the whole solution in .NET 10, with DDD, CQRS, an API gateway, Docker, integration events and its own test suite. I build it coordinating AI agents, and that tooling is open source: [baton](https://github.com/andrey342/baton) and [foreman](https://github.com/andrey342/foreman).

Before that, 6+ years shipping .NET and Angular to production in logistics, port operations, security, social care and IoT.

📍 Madrid, Spain · I share the build on [X](https://x.com/andreykuzmin342) and [LinkedIn](https://www.linkedin.com/in/andrey-kuzmin-developer)

### 🚀 Featured work

- **MSG / MicroservicesGenerator** *(private, in progress)*: visual designer for .NET microservice solutions. Model aggregates, value objects, commands, queries and integration events, and get .NET 10 code with DDD + CQRS, EF Core, a YARP gateway, Docker, CAP + Kafka/Redpanda messaging and generated tests. Live build pipeline, ZIP download or publish to GitHub, and a read-only MCP server so AI agents can query your solutions.
- **[baton](https://github.com/andrey342/baton)**: Claude Code plugin with no code that runs a written plan part by part from one chat: each part in its own nested session, a fresh reviewer checks it until it's OK, and the chat supervises and delivers (branch, PR or merge). It's how I build MSG.
- **[HexaFleet](https://github.com/andrey342/hexafleet)**: vehicle renting microservice in .NET 9 on hexagonal architecture and DDD, with use cases and output ports, MediatR, MongoDB transactions, Testcontainers tests and Docker Compose.
- **[Tramo](https://github.com/andrey342/tramo)**: education-financing backend that scores applications, signs loan or income share agreements and collects SEPA instalments. A NestJS modular monolith of hexagonal modules with a transactional outbox, BullMQ, PostgreSQL and Redis.
- **[foreman](https://github.com/andrey342/foreman)**: baton's predecessor. It runs long work as background threads (implement → review → apply), with a watcher and a fixed state machine, so the coordination costs no tokens.
